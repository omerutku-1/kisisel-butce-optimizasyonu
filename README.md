# 📊 Personal Budget and Spending Optimization

This project was developed by an Industrial Engineering student to apply linear programming (operations research) and data analysis concepts to a real-world financial problem.

## 🚀 Project Objective
The goal is to determine the optimal budget allocation that **minimizes life quality (utility) loss** while respecting monthly income constraints, savings targets, and essential living expenses (food, transportation, bills, etc.).

## 🛠️ Tech Stack & Libraries
* **Python** (Programming Language)
* **Pandas** (Data Analysis & Manipulation)
* **Matplotlib / Seaborn** (Data Visualization)
* **PuLP** (Linear Programming & Optimization)

## 🧮 Mathematical Model (Operations Research)
* **Objective Function:** Minimization (minimize deviation from original spending levels)
* **Constraints:**
  - Lower bounds for essential expenses (food, transportation).
  - Fixed costs (monthly bills).
  - Total spending upper limit: `Total Income - Target Savings`.

## 📈 Methodology
1. Created a sample spending dataset (`DataFrame`).
2. Performed exploratory data analysis and visualization with Pandas & Matplotlib.
3. Formulated and solved a constrained optimization problem using the PuLP library.
